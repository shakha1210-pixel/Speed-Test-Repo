# ⚡ speedtest-cli

Консольный скрипт на Python, который замеряет скорость скачивания: делает **10 последовательных запросов** к заданному адресу, дожидается полного ответа на каждый и печатает среднее время, общий объём и скорость.

Без зависимостей — только стандартная библиотека Python.

## Требования

- Python 3.8 или новее (Windows / macOS / Linux)
- Веб-версия: любой современный браузер. Для 3D-фона нужен WebGL, без него сайт работает без фона. Интернет нужен для загрузки Three.js и шрифтов.

## Запуск

```bash
python speedtest.py <URL>
```

На macOS и Linux команда обычно `python3`.

Пример:

```bash
python speedtest.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Дополнительные параметры (необязательные):

| Параметр | Значение | По умолчанию |
|---|---|---|
| `-n`, `--count` | количество запросов | `10` |
| `-t`, `--timeout` | таймаут сети, секунд | `30` |

```bash
python speedtest.py https://example.com/big.jpg -n 5 -t 15
```

Справка: `python speedtest.py --help`

## Единицы измерения

- **Скорость** — **Мбит/с** (мегабиты в секунду): так провайдеры указывают скорость тарифа. Рядом для удобства показан эквивалент в **МБ/с** (мегабайты в секунду).
- **Объём** — Б / КБ / МБ / ГБ в **десятичной** системе: 1 МБ = 1 000 000 байт.
- **Время** — миллисекунды (мс).
- Перевод: `Мбит/с = байты × 8 ÷ секунды ÷ 1 000 000`.

## Как считаются числа

- **Время запроса** — от момента отправки запроса до получения последнего байта ответа (включая установку соединения). Часы — `time.perf_counter()`.
- **Среднее время** — сумма времён успешных запросов ÷ их количество.
- **Общий объём** — сумма байтов всех успешных ответов (считаются реально прочитанные байты, а не заголовок `Content-Length`).
- **Скорость скачивания** — общий объём ÷ общее время. Так честнее, чем среднее арифметическое скоростей отдельных запросов: быстрые мелкие запросы не искажают итог.

## Как устроен код

| Часть | Что делает |
|---|---|
| `download()` | скачивает URL целиком кусками по 64 КБ, возвращает `(байты, секунды)` |
| `main()` | проверяет аргументы, в цикле делает N запросов, печатает итоги |
| `mbit_per_s()` / `format_size()` | перевод байтов и секунд в удобные единицы |
| `paint()` и цветовые хелперы | ANSI-цвета; отключаются автоматически, если вывод не в терминал, либо при `NO_COLOR=1` |

## Обработка ошибок

- Некорректный адрес или `-n < 1` → понятное сообщение, код выхода `2`.
- Сетевая ошибка / таймаут / HTTP-ошибка на одном из запросов → запрос помечается `✗`, в статистику не попадает, остальные продолжаются. Код выхода `1`, если была хотя бы одна ошибка.
- Все запросы упали → выводится сообщение, код выхода `1`.
- `Ctrl+C` → аккуратное завершение.

## Веб-версия (бонус)

В папке `docs/` лежит `index.html`: тот же замер в браузере, с фоновой 3D-сценой. Сцена реагирует на скорость: во время замера она ускоряется.

В интерфейсе два режима:

- **Скачивание · URL**: 10 последовательных запросов к адресу, как в консольной версии.
- **Загрузка · файл**: выбираете файл кнопкой или перетаскиванием. Файл отправляется 10 раз на `speed.cloudflare.com/__up`, измеряется скорость **загрузки**. Если файл не выбран, отправляется тестовый набор ≈5 МБ.

**Как открыть:** двойным кликом по `docs/index.html` или онлайн через GitHub Pages: `https://<ваш-логин>.github.io/<название-репозитория>/`.

**Как включить GitHub Pages:** репозиторий → *Settings* → *Pages* → *Build and deployment* → *Deploy from a branch* → ветка `main`, папка `/docs` → *Save*. Через минуту-две сайт станет доступен.

**Отличия от консольной версии:**
- Браузер разрешает читать ответ чужого сервера, только если тот присылает заголовок `Access-Control-Allow-Origin` (CORS). Поэтому веб-версия работает не с любым адресом, а консольный скрипт — с любым.
- Загрузка отправляет файл на сторонний сервер (`speed.cloudflare.com`). Не выбирайте приватные файлы.
- Скорость загрузки обычно ниже скорости скачивания, поэтому смотрите оба режима отдельно.

### Как устроена веб-версия

| Часть | Что делает |
|---|---|
| `download()` | читает ответ кусками через `fetch` и `ReadableStream`; время — до последнего байта |
| `upload()` | отправляет файл через `XMLHttpRequest`, потому что только он даёт прогресс отправки |
| `paintLane()` | обновляет шкалу запроса и передаёт скорость в 3D-сцену (переменная `pulse`) |
| `initScene()` | 3D-сцена на Three.js: ядро, кольца, частицы и перспективная сетка |

## Ограничения

- Измеряется скорость до **конкретного сервера**, а не «скорость интернета вообще»: на результат влияют CDN, кэш, загрузка сервера.
- Запросы идут последовательно в одном потоке, поэтому на очень быстрых каналах результат может быть ниже предела канала (один TCP-поток).
- Сжатие (`gzip`) не запрашивается, поэтому считается реальный размер файла.
