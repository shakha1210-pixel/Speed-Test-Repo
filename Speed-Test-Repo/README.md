# ⚡ speedtest-cli

![CI](https://github.com/shakha1210-pixel/Speed-Test-Repo/actions/workflows/ci.yml/badge.svg)
![Python](https://img.shields.io/badge/python-3.9%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

Консольный скрипт на Python, который замеряет скорость скачивания: делает **N последовательных запросов** (по умолчанию 10) к заданному адресу, дожидается полного ответа на каждый и печатает среднее время, общий объём и скорость.

Без зависимостей — только стандартная библиотека Python.

## Возможности

- Последовательные запросы с полным скачиванием тела ответа
- Среднее время, общий объём и скорость (Мбит/с и МБ/с)
- Прогресс в реальном времени и визуальная шкала
- JSON-режим для скриптов и автоматизации (`--json`)
- Корректная обработка ошибок и коды выхода
- Цвета отключаются автоматически при перенаправлении вывода или `NO_COLOR`
- Веб-версия (только скачивание) в `docs/` — работает через GitHub Pages

## Требования

- Python 3.9 или новее (Windows / macOS / Linux)

## Быстрый старт

```bash
python speedtest.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

На macOS и Linux команда обычно `python3`.

### Установка (опционально)

```bash
pip install .
speedtest https://example.com/big.jpg
```

## Параметры

| Параметр | Описание | По умолчанию |
|---|---|---|
| `url` | адрес, к которому идут запросы | — |
| `-n`, `--count` | количество запросов | `10` |
| `-t`, `--timeout` | таймаут сети, секунд | `30` |
| `--json` | вывести итог в формате JSON | выкл |
| `--version` | показать версию | — |

Примеры:

```bash
python speedtest.py https://example.com/big.jpg -n 5 -t 15
python speedtest.py https://example.com/big.jpg --json
```

Справка: `python speedtest.py --help`.

## Единицы измерения

- **Скорость** — **Мбит/с** (мегабиты в секунду): так провайдеры указывают тариф. Рядом показан эквивалент в **МБ/с** (мегабайты в секунду).
- **Объём** — Б / КБ / МБ / ГБ в **десятичной** системе: 1 МБ = 1 000 000 байт.
- **Время** — миллисекунды (мс).
- Перевод: `Мбит/с = байты × 8 ÷ секунды ÷ 1 000 000`.

## Как считаются числа

- **Время запроса** — от отправки запроса до получения последнего байта ответа (включая установку соединения). Часы — `time.perf_counter()`.
- **Среднее время** — сумма времён успешных запросов ÷ их количество.
- **Общий объём** — сумма реально прочитанных байтов всех успешных ответов (не заголовок `Content-Length`).
- **Скорость** — общий объём ÷ общее время. Это честнее, чем среднее арифметическое скоростей отдельных запросов.

## Коды выхода

| Код | Значение |
|---|---|
| `0` | все запросы успешны |
| `1` | хотя бы один запрос завершился ошибкой |
| `2` | ошибка аргументов (неверный URL, счётчик или таймаут) |
| `130` | прервано `Ctrl+C` |

## Веб-версия

В `docs/index.html` лежит тот же замер в браузере: последовательные запросы к адресу и живая 3D-сцена, которая реагирует на скорость. Загрузка файлов с локального ПК в веб-версии отсутствует — только скачивание по URL.

**Как открыть:** двойным кликом по `docs/index.html` или онлайн через GitHub Pages.

**Как включить GitHub Pages:** *Settings → Pages → Build and deployment → Deploy from a branch →* ветка `main`, папка `/docs` → *Save*.

**Ограничение:** браузер разрешает читать ответ чужого сервера, только если тот присылает заголовок `Access-Control-Allow-Origin` (CORS). Консольный скрипт работает с любым адресом.

## Ограничения

- Измеряется скорость до **конкретного сервера**, а не «скорость интернета вообще»: на результат влияют CDN, кэш и загрузка сервера.
- Запросы идут последовательно в одном потоке — на очень быстрых каналах один TCP-поток может не упереться в предел канала.
- Сжатие (`gzip`) не запрашивается, поэтому считается реальный размер файла.
