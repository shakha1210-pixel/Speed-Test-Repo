Измерьте скорость загрузки

Последовательные запросы к выбранному адресу. Каждый ответ загружается полностью — время фиксируется до последнего байта. 3D-сцена реагирует на скорость соединения.

Примеры адресов:

    ТЕКУЩАЯ СКОРОСТЬ ЗАГРУЗКИ

    —

    Мбит/с

    Среднее время ответа
    —
    Загружено данных
    —
    Успешно выполнено
    —

    Консольная версия: python speedtest.py <URL>. Скорость = общий объём данных ÷ суммарное время загрузки. 1 МБ = 1 000 000 байт.
